How to Connect to Real WhatsApp (Live Meta Webhook)

We built the full Meta WhatsApp Cloud API protocol into issue-service. Here is how you can hook it up to a real WhatsApp Business phone number:

1

Meta Developer Portal

Create a free account on developers.facebook.com. Create an App and add the WhatsApp product. Meta provides a free sandbox test phone number.

2

Configure Webhook URL

In Meta Dashboard → WhatsApp → Configuration → Callback URL, set: https://your-domain/api/issues/webhook/whatsapp Verify Token: civicconnect_token

3

Subscribe to Messages

Under Webhook fields, click Subscribe for messages. Now, whenever anyone sends a message or photo on WhatsApp, Meta forwards it straight to our cloud backend!
